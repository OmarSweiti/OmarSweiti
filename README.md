## About

I'm a Computer Engineering graduate from the University of Jordan working at the point where
software delivery meets infrastructure — Linux systems, containers, CI/CD, and the performance
characteristics of distributed applications under real load.

My path here has been deliberately broad: administering Linux and distributed compute for EDA
workloads at **Synopsys**, then load- and stress-testing production systems to find their breaking
points at **Q-Pros**. Alongside that I build and ship full-stack applications — NestJS and Next.js
on Prisma/PostgreSQL, containerized with Docker — because knowing how an application is built makes
me far better at running, scaling, and debugging it.

**Currently:** Datakite.ai &nbsp;·&nbsp; **Open to:** DevOps, Platform, and Cloud Engineering roles

## Selected Work

**[financial-transaction-monitor](https://github.com/OmarSweiti/financial-transaction-monitor)** — Full-stack transaction monitoring dashboard. A NestJS + Prisma + PostgreSQL API with a rules-engine interceptor that forces any transaction over 5,000 into `PENDING_REVIEW` before persistence, paired with a Next.js 16 / React 19 frontend using TanStack Query and Recharts. Runs on Docker Compose with soft deletes, graceful shutdown hooks, and indexed query paths.
`TypeScript` `NestJS` `Next.js` `Prisma` `PostgreSQL` `Docker`

**[fullstack-capstone-project](https://github.com/OmarSweiti/fullstack-capstone-project)** — *GiftLink*, a platform connecting people giving away household items with people looking to reuse them. React frontend, Node/Express backend, plus a separate sentiment-analysis service.
`JavaScript` `React` `Express` `MongoDB`

**[odoo-dev](https://github.com/OmarSweiti/odoo-dev)** — Odoo development environment with custom addons, exploring ERP customization in Python.
`Python` `Odoo`
